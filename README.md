# Shahn · شحن

<img src="icon.png" width="96" align="right" alt="Shahn icon">

Battery rings for your laptop and every connected device (mouse, keyboard, headset, controller), plus a
live network speed readout, on the stock Windows 10/11 taskbar just left of the tray. About 1 MB on disk.

- One ring per device, colored by level and animated while charging; hover for name, level and last report.
- Download and upload speed, refreshed every second. Right-click the strip and untick **Show network speed** to hide it.
- Hides over full-screen apps, follows the taskbar across monitors and DPI, starts with Windows (optional).

## Download

Get `Shahn-<version>-win-x64.zip` from the [latest release](https://github.com/mfathy234/shahn-releases/releases/latest),
unzip it anywhere and run `shahn.exe`. Check the download against the `.sha256` file next to it.
Settings live in `%APPDATA%\Shahn\config.toml` (right-click the strip > **Open config file**); `shahn --quit` stops it.
